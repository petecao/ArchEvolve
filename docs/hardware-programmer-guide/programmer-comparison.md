# Programmer comparison: assistance, operands, and updates

Bound to published `e4a709c`, catalog revision 0.1.17. The 20 rows preserve the separate DX100 paper/artifact records and Terminus configurations. Labels describe the admitted mapping, not an exhaustive capability claim about an entire machine.

## Three different programming contracts

| Contract | What is supplied | What the program must still do | Small explicit example |
|---|---|---|---|
| **P: prefetch assistance** | Speculative cache warming; optional work can be dropped. | Execute the required architectural load and its dependent computation/update. Do not substitute a prefetch event for a returned value or completed update. | Prodigy can run ahead through a DIG edge toward `A[B[i]]`; the CPU still executes the load needed by the program. SVR/Triangel likewise supply assistance, not architectural results. |
| **R: required operand delivery** | A required value/operand through a queue, callback, tile, or staged memory path. | Supply valid inputs/ownership, consume the correct delivered operand, perform any arithmetic/updates left by that mapping, and bind completion/reuse. | MAPLE's concrete interval in [concrete-flows.md](concrete-flows.md) supplies `P,Q` in queue order. TMU supplies the two row operand vectors; CPU ri/re performs arithmetic and the store. |
| **U: update engine** | Selected memory/key-map effects, sometimes a status/old-value result. | Prove the operation/order is legal, preserve ownership, and establish update visibility before dependent reads. Do not assume every update returns an old value or supplies CAS. | PHI ingests address/value updates during a relaxed bulk phase; replay/flush and phi_sync precede reads. Terminus CAS supplies an explicit success result in its configured mapping. |

Other scopes must remain visible: **T** is tuple collection/regrouping for later software updates, **M** is metadata/index discovery, and **C** is mapped computation (or its model). They do not become generic gathers or update engines merely because they touch memory. COBRA emits bins for CPU Accumulate; SMASH emits coordinates for CPU loads/arithmetic; Azul performs mapped local work and exchanges messages; Telos is a public cycle-model record.

The labels can overlap within a design. MAPLE has both queue-delivery and prefetch modes, SpZip's required traversal stream coexists with destination prefetch, and DX100 combines reads with selected updates. A configuration or operation choice determines the contract.

## Choosing a mapping without losing program semantics

1. **Name the required result.** Is it a cache hint, an actual operand, a coordinate/tuple, an updated destination, or a key-map status/victim? These outputs are not interchangeable. In particular, COBRA binning does not update the application's destination, and an HTA swap victim is not the requested key's old value.
2. **List the remaining CPU work.** A delivery engine can remove traversal/fetch work while leaving multiply/reduction/store callbacks on the CPU. Metadata production can leave both operand loads and arithmetic. A deferred configuration deliberately leaves its deferred operations on the CPU.
3. **Bind ownership and mutation timing.** MAPLE's fetched queue value does not follow later writes. PHI's bulk discipline forbids intervening reads and conventional-atomic mixing in the updated region. Terminus partition serialization still needs cross-core synchronization; HTA's unresolved software path needs its lock/recheck protocol.
4. **Choose the correct completion boundary.** Produce acknowledgement, callback order, result readiness, drain, reusable storage, and memory visibility are different obligations. Unknown exact fences/encodings remain unknown; use the source-bound interface rather than inventing one.
5. **Keep numerical and status semantics.** Required operands alone do not certify reduction order. Tuple reordering is not blanket floating-point permission. A resolved miss/fallback/victim must retain its documented meaning. A model/scaffold output is not a hardware measurement.
