# Retained scientific bundle v3

`scientific-bundle-v3/catalog.json` is frozen at SHA-256
`42100d4ecb63de8718f6d16071f179ba3fb173cd94511730b195106426a1cb60`.
Copy only `catalog.json` and `objects/` when creating a portable fixture. The
catalog pins every object, so its hash is the aggregate bundle identity. The
bundle is 9,378,545 bytes, with 91 JSON objects; its largest document is
3,890,086 bytes. Every document is below 4 MiB and the fixture is below 16 MiB.

This is retained conditional mathematical evidence. It creates no source,
Typed, allocator, body, caller, public-record, or ticket admission. The current
production binder must independently reconstruct the required source targets
and validate this evidence. Historical absolute paths inside payloads remain
inert metadata; the portable validator must never open them.

## Portable interface

The catalog contains a `components` array with fixed IDs and accepted target
counts: `constructor` 35, `destructor` 11, `private_frame` 9, `gluing` 4, and
`positive` 23. These are 82 source targets. The constructor numeric C kernel
generates several obligations, so the accepted targets contain 91 ordinary
goals and one healthy nonproof smoke result. The complete retained census is
90 native report rows: 89 ordinary Valid rows and one smoke Timeout. Two
constructor numeric ordinary goals are passed inventory-only. There are 175
registered property entries. No inventory-only or smoke result is relabeled a
direct native mathematical proof.

Each explicit document reference has exactly `path`, `sha256`, and `bytes`;
its path is `objects/<sha256>.json`. A location has `document` and an RFC 6901
`pointer`. Each target has `id`, `input_sha256`, `kind`, canonical `goal`,
`statement`, a `canonical_obligation` location, and an `observation` object.
The constructor numeric target preserves its canonical `statement: null` and
`kind: c_kernel`. Its complete native and normalized census stays in
`native_results_by_goal` and its retained run context.

The observation's `evidence` points to the actual retained per-target run or
leaf. Constructor and destructor observations preserve actual normal-reader
checks and complete native/ordinary/CSV reports. Gluing and positive leaves
retain their explicit normal verdicts and exact native attempt sequences.
Private-frame leaves originally omitted the already checked normal verdict;
the primary objects retain that omission. Their observations instead expose
`reconstructed_normal_verdict` and `normal_verdict_basis`, naming the reviewed
observer, its exact assertion, the result pin, the raw outcome pin, and the
accepted scope. This is not represented as a directly emitted leaf field.

Each component's `historical_identity` preserves its actual source commit,
method ID/artifact, reader check, domain where recorded, expected policy, and
source context. The two historical domain-3 aggregate hashes differ and stay
distinct. The `accepted_decision` resolves to the exact parsed historical root
decision. `cold_evidence` and `context` retain complete source, task,
hypothesis/support, import, runtime/tool/config, consumer, guard, raw manifest,
and source-inverse metadata. Historical setup/reader fixture versions and
actual per-run checks are kept separately. No current record is fabricated.

Only `receiver.entry`, `constructor.frame`, `buffer.identity`, and
`zero.cleanup` are accepted from the original six-target gluing run. Both
original positive targets retain `not_proven` and their exact
`[timeout, unknown, timeout]` sequences. The later 23-target profile retains
its separate accepted outcomes and explicit reference reconstruction; it does
not rewrite the original timeouts.

## Serialization and provenance

Objects contain canonical JSON values. `retained_origins` pins the original
local JSON bytes, while `document_provenance` gives their source pointer and
serialization operation. Ninety-nine provenance rows preserve their JSON
values exactly. Two rows explicitly describe derivations: the constructor
capture envelope omits the separately retained `metadata` field, and the
destructor exclusion object contains hash/length descriptors for raw canonical
C, raw theory, and a bootstrap command. Those raw payloads remain outside the
bundle. Complete canonical source statements, input hashes, and source/theory
inverse context remain available in the retained JSON.

V1 and v2 are preserved authoring history. V2 made the destructor physical
method artifact shape consistent. V3 corrects only the two provenance labels;
all 91 objects and all source-target/outcome values are byte-identical to v2.

`verify-scientific-bundle-v3.py` checked all object hashes, 300 locations, 101
origin-value or explicit derivation rows, all 82 canonical identities and
statements, historical accepted subsets, complete normal/native census, and
four fail-closed tamper controls. It used local standard-library JSON/file
operations only: no project import, SSH, child process, compiler, verifier,
native helper, or solver. These are metadata integrity controls, not a new
scientific proof run. Required retained details were found locally, so no
remote inspection was needed and the catalog's `gaps` array is empty.
