The original version2 growth contract admits borrowed backing storage and
receiver/backing overlap. That retained counterstate remains a real domain
defect. The repaired domain must be explicitly versioned: initialized receiver
fields and extent; size/capacity bounds; owned dynamic backing when nonempty;
valid initialized element objects; receiver/backing separation; and live
allocation identity/provenance. A two-receiver operation also requires a checked
source identity/ownership relation, including self-alias cases and ownership
transfer. Unary `freeable(buffer)` does not prove unique ownership across two
different vectors.

The domain may be derived for source-created local objects from the exact
constructor/allocation trace. It must not be granted merely because a name says
`vector`, a pointer map contains values, or a C struct satisfies the old unary
representation. Generic external vector references, escaped pointers and
unreconstructed ownership transfer remain unsupported until their source rule
exists. Fresh administrative scalar/parameter storage is a separate private
component, not hidden changes to the selected Heap identity counter.

The next production seam is an isolated reusable source/evidence validator. It
should accept a freshly reconstructed source/domain certificate and a complete
scientific bundle, match every logical target and full hypothesis/import closure,
and retain each producer's actual historical method/compiler/checker identity.
The checked source effect rule and explicit allocator/library TCB justify the
domain and original observation. A matching report hash or an old record name
does not admit a current original model. The ordinary generic dependency reader
must keep its present identity checks until this distinct scoped route is
implemented and reviewed.

Source versioning must preserve the currently frozen version2 implementation and
all qualified body bytes. Changing the global `std_models.identity()` now would
invalidate every in-flight exact source check and the explicit version2 gate in
the closed view. A reviewed version selector/archive or separate owned-model
registry is needed before a repaired domain becomes the default. The source

release correspondence explicitly, alongside library correspondence and normal
allocation success. Neither linked replacement absence nor hidden allocator
