# Checked-body whole-interface model assembly

2026-10-16 ET. The model emitter now assembles the concrete checked C bodies for
all 26 source names, 27 declarations and 132 exact type/arity routes. It preserves
the four independently reviewed value/backend headers, builds the 11 direct
packet-family routes, and re-renders the pointer/CPU bridge and typed wrappers
from a supplied ABI and complete ordinary-object atlas.

The new contract form binds each call to its specific normal-return state/value
relation, source citations and owned compiler/MMIO/numeric rules. CBMC must run
the concrete bodies with all guards and original source assertions. No empty
ACSL summary, unreachable body or assumed call precondition represents this
form. WP is explicitly unsupported until a separate concrete-body/frame proof is
implemented. Existing layouts and the readable 0.1 entry are unchanged.

The only finite semantic choices use independent uint32 harness draws. The
default table has 128 draws; both choice range and exhaustion are fatal checked
properties. Modulo reaches every permitted alternative. A future public harness
consumer must fill each entry independently and record that draw plan in the
method identity before executing the source unit. This emitter supplies neither
those draws nor a proof that a caller used the correct harness.

The emitter grants no source admission, fresh zero device, payload initialization
or ownership. The public consumer must bind actual source globals, receiver
state, the complete same-TU declaration/ABI observation, expression evaluation,
ordinary-object lifetime/projection and every CPU access. Calls to reset are not
added by assembly. The existing explicit backend reset definitions are retained.
The checked body uses the same atlas cells and physical spans for CPU/device
effects, including complete ordinary/MMIO exclusion.

Six pure no-child controls cover the exact composition, all call/value rows,
complete choice domain and budget, old-version/public-boundary preservation,
actual emitter ABI/MMIO refusals, frozen identities and deleted/duplicate/missing
overload contract refusals. A first test incorrectly searched for reset calls
inside the preserved backend definitions; it was corrected to check that the
emitter adds no invocation. The production model was unchanged by that test fix.

The generated demonstration artifacts deliberately use the previously pinned
illustrative ABI and object addresses. They remain preparation only. Source
compiler admission, native checking of this composition, the new public
validator/lowering/method integration and actual predicted verdicts are required
before this can become a current 0.2 entry. No whole-ticket acceptance follows.
