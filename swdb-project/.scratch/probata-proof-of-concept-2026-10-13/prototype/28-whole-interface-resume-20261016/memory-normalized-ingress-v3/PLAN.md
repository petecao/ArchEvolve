# Explicit semantic ABI reader for the G642 memory observer

2026-10-16 ET.

This source-only successor keeps the genuine G642 source55b9 capture, adopted
memory normalized transport, full same-TU graph, all 40 calls and three independent
12/14/14 call selections. It does not borrow the first3148 transport. The exact
source selection, body/CPU/lifetime consumer, source facts and all other module
bytes remain unchanged.

The fixed package includes both real v3 and semantic v4 reader files. The memory
adapter imports v4 explicitly as consumer, checks its physical hash before/after,
and preserves original, role-derived and interpreted ABI identities. Ingress
pins that same module, requires object identity with source.semantic_compiler,
and uses it for the subsequent normalized graph parse. The old source.compiler
binding remains v3. No compatibility overlay or monkeypatch is used.

Fifteen modules plus the source-facts JSON, inventory and entry form 18 closed
observer controls. Five no-child controls pass: exact inverses/unchanged modules,
distinct reader pins, real physical and object-identity gates, all 18 staged reads
with substitution refusal, genuine memory roles and unchanged three-root source
consumer. The adapter tail with the actual small ABI metadata is independently
covered by first observer V5. These controls do not consume the complete 177 MiB
TU and do not emit a preparation or owned context.

The new observation policy is fully populated from retained actual source and
transport metadata and keeps prepared:null. Its new raw namespace is prospective.
Root must select the actual memory lane/guard and admit an outer envelope before
execution. Actual preparation, ordinary mapping, receiver, owned context, source
body and public acceptance remain absent; none is fabricated here.
