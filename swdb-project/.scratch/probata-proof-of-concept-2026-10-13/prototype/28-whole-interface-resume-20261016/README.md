# Whole-interface source preparation

2026-10-16 ET. Private, compiler-free preparation. Owned source/model/MMIO
correspondence is an explicit trusted premise. No hardware refinement theorem is
required for this engineering path. These files do not promote public version0.2.

The first slice closes the source/type/arity dispatch inventory and prepares
private command wrappers. It covers27 declarations,26 distinct names,11 packed
command mappings and132 scalar instances in one clearly synthetic ABI fixture.
`contracts.json` has one key per name; `get_new_reg` retains its two separate
overload recipes. Each recipe retains exact header/body pins, line citations,
value behavior, checked domains and owned premises.

The compiler metadata in these controls is hand-authored. It checks the consumer
protocol; it is not actual Clang output or actual source-call admission. Source
preparation executed no compiler, native binary, verifier, SSH or project module.

The dispatch binder accepts a direct global definition from the exact pinned
header and rejects macro coordinates, wrong IDs/signatures/arity, namespaces,
static definitions, attributes, effectful arguments, stale source/registry and
ABI changes. It requires standalone packet statements and an ASCII caller so
compiler byte offsets coincide with source offsets. The external admitted
producer must supply normalized full-TU locations and a compiler-bound ABI.
Bindings retain complete TU-metadata and ABI hashes and must replay immediately
before use. This parser is a consumer of compiler evidence, not a C++ parser.

The role bridge preserves source first-ID/F2 regions, separate explicit and
physical masks, full-line stores, global-instance conflicts and per-thread
ownership. A condition-only tile is not counted readiness; both halves of an
eight-byte source/destination are counted. Comparisons write four bytes.
`maa_range_loop<T>` always dispatches INT32. Unsupported NE16, floating bit/shift,
RMW/reduction operation domains and physical-pair/width conflicts refuse.

The geometry is an explicit caller-selected private4/8-core profile, with
`NUM_TILES=NUM_CORES*8`, source tile stride16384 words and a two-element value
prefix. Source16-core geometry exceeds the current64-bit role masks. All
capacity/prefix/initializedness/ownership/domain checks remain obligations.
Memory preparation currently requires nonempty logical and physical envelopes;
zero-length streams and all-inactive indirect calls remain outside that domain.
The supplied envelope must cover every possible deferred active address.

The atomic packet wrapper prepares, invokes one private source-owned builder,
then binds its complete root with no intervening source action. An arbitrary
callback does not implement a value model. Candidate code must never receive
private entry points, builder pointers, contexts or runtime-policy setters.
The follow-on value-builder slice will supply frozen implementations for this
seam without changing the original backend files or this first packet.

The concrete production path is:

1. Add a new closed source-definition policy at the existing
   `c_lowering.py`/`proof_semantics.py` allowlists. Feed its admitted full-TU
   declaration and compiler ABI to `bind_call`, then independently replay the
   binding before lowering/model use. Preserve all existing default refusal,
   provenance and source-defined-body gates; never use a name-only bypass.
2. Route effective arguments using `dispatch_plan`. RF scalar parameters/results
   need exact object-representation bit copies for all six canonical types.
   Template selection uses actual typedef identity, not matching width.
3. Bind closed family builders to immutable tile/RF/size captures and typed
   history/action nodes. Values and size bounds must settle at cover, including
   arithmetic/source-undefinedness checks only on selected active expressions.
4. Instrument actual CPU accesses with compiler-bound C-object/guest/physical
   mapping. Pointer-helper adapters currently return modeled guest identity;
   they grant no host pointer, ownership, initializedness or completion. Ordinary
   array writes/CAS and every physical line must agree with the memory history
   model. Noncacheable pointer dereferences need their own admitted access policy.
5. Freeze the complete source/model/runtime profile, generate the new public
   contract entry and run public synthetic proof/refusal verdicts through the
   retained evidence consumer. No such verdict is claimed by this slice.

The remaining work is compiler integration, concrete deferred family builders,
pointer/scalar routing, and actual public evaluation under the owned MMIO
premise. It is not an optional hardware/body theorem dependency.
