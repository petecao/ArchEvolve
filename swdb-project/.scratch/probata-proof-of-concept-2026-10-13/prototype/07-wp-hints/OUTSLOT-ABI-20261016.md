# Prospective private output-slot ABI

2026-10-16 ET. Implementation and native controls only. No ACSL parsing,
RTE generation, solver run, helper proof or TDStep proof has been performed for
this method. The original `standin/` inputs and all prior proof records remain
unchanged. `standin_outslot/` is a separate prospective hand model, generated by
`outslot_lowering.py`; it is not selected by the existing proof driver.

The finite generator accepts only four exact source hashes recorded in
`standin_outslot/abi-map.json`. It refuses changed source before writing output.
This is a mechanical rewrite of an already hand-made C model, not a general C++
lowering. The map retains every original returning-interface contract, the new
contract, exact result type, declaration/body classification, source locations,
and input/output hashes. A new method and fresh proof records are mandatory.

## Why this interface

The frozen helper run completed all 245 generated goals but left three ordinary
goals open. Source inspection found WP's call-return value equality does not
perform the same initializedness transfer as a normal typed memory store. This
motivates an explicit store in the prospective C model; it does not establish a
general verifier defect or prove these new goals will close. The independent
source-pinned design is retained externally in
`/private/tmp/probata-t07-helper-sound-repair-options-20261016.{md,json}`.

Every returning interface becomes a `void name_out(..., T *swdb_out)` procedure.
The output object has the exact former return type, including `uint16_t` for the
device tile size. The old result predicate becomes the same predicate on
`*swdb_out`. The old frame gains only `*swdb_out`; the helper body performs a real
typed assignment. Each helper's new output initializedness postcondition must be
proved from that store, rather than accepted as a new helper assumption.

For an existing bodyless summary, the new contract specifies the typed store of
the original operation's defined normal return. The old value/state relation is
retained. Validity of the private output and separation from source objects are
lowering obligations. Initialization of a returned pointer object never implies
initialization of the pointed-to array. CAS/load still require initialized source
cells; copy still requires initialized source elements. This adds no assumption
that an unsafe source return expression is initialized.

## Evaluation and private memory obligations

Each operation call receives the address of a fresh automatic scalar or pointer
object. The rewrite does not initialize these result slots before the call.
The slot's type, size, alignment and lifetime follow ordinary C automatic object
construction. Source inputs remain live separate objects. No slot address is
stored into source state, returned, registered with the device, or used as a
source array. No slot lives across the end of its enclosing block. Slots are
consumed only after the call, with an ordinary assignment where the source had a
destination. The two atomic wrappers likewise use their own fresh local slots
before writing the wrapper's caller slot.

The added output validity/separation requirements are discharged by this private
construction, not imposed as extra desired-result assumptions on the original
TDStep caller. The public generated C ABI alone is not a runtime alias checker:
an arbitrary caller that aliases an output with source state violates the
lowering domain and cannot claim source equivalence. The admitted source has no
such caller; changing it is refused. Native type diagnostics check the result
declarators, while formal output validity/separation and frame discharge remain
unrun and mandatory before proof acceptance.

Short-circuit operands remain conditional: queue size is called only if
acceleration is enabled, and index/CAS are called only for a negative hint/value.
The `false` accumulators encode the source short-circuit result; they are separate
from the uninitialized result slots. The scalar loop reevaluates its end accessor
before every test and increments after each completed iteration. Registration
arguments are evaluated left to right, choosing one permitted order for the
source's pure, nonvolatile accessor arguments. All source side effects retain
their original sequence points and single evaluation. New side effects touch
only private slots. The original TD functional postconditions are retained
verbatim and hash-bound in the map.

## Element spans and source provenance

The old byte-offset representability bound is replaced by a bounded element-count
and endpoint witness, before any remaining typed pointer difference or order.
The copy summary takes an explicit `size_t swdb_count`; flush supplies the
existing symbolic `self->in`, and requires `last == first + swdb_count` plus the
live span. Copy content, final pointer, output initializedness and frame clauses
use that same count. There is no new scaling axiom or computed desired result.
The existing `in <= local_size <= 16384` and queue-capacity domains supply the
caller counts. Every data dimension and build knob stays symbolic.

`gapbs_nodeid_span(base,count)` requires `0 <= count <= PTRDIFF_MAX`, the live
typed cell range and a formed endpoint. Vector domains existentially identify
the end as `start + count`; capacity endpoints have their own count witness.
The source-backed interpretation is one contiguous live typed array object,
not two arbitrary pointers with equal allocation bases. Base equality is no
longer used to establish this span. Remaining base comparisons only express
separation/registered-memory identity, as before.

The physical same-array claim comes from exact `arkhadem/DX100` e4fc4af source
producers: `pvector`'s `new T[n]` storage, `SlidingQueue`'s `new T[shared_size]`,
QueueBuffer's `new T[local_size]`, and default CSR construction's typed neighbor
and index arrays. These source allocation/lifetime facts must be related to the
hand model explicitly. WP's flat typed allocation/range predicates do not prove
C++ array-subobject provenance or physical alignment for arbitrary Graph inputs.
Neither this definition nor a successful Typed proof would close that boundary.

The exact default producer map and pins are retained at
`/private/tmp/probata-t07-source-model-alignment-caller-domain-20261016.{md,json}`.
Arbitrary public `Graph` pointer producers and the `-m` in-place EdgePair/type-pun/
`realloc` path are unsupported. This is not a new premise inserted to obtain the
desired TD postcondition. It is an explicit restriction to the existing default
typed producers, whose whole-program caller, allocation, initialization, OpenMP,
layout, device and source-correspondence obligations remain open.

## Allocator correspondence is refused

The inherited `swdb_lqueue_storage` global is implicitly zero-initialized by C.
It cannot represent the initial uninitialized payload of `new NodeID[n]`.
The pointer-output interface itself does not initialize that payload, but the
old fixed-storage abstraction already does so implicitly. The generated map
therefore says `REFUSED_PENDING_SEPARATE_REPAIR`, and the generator's public
`--require-allocator-correspondence` gate refuses before emitting output.
No full source/TD or new counted proof admission may use this package while that
gate remains closed. Helper diagnostic generation may be reviewed with this
explicit boundary; it is not allocator or source proof acceptance.

A separate source-backed fresh typed allocation abstraction must preserve live
array validity, alignment, ownership, lifetime, nonescape, deallocation family,
normal-return behavior and genuinely unconstrained payload initializedness.
Its negative controls must use the same allocation path as TD/helpers. No
`calloc`, global-zero surrogate, initializedness premise, synthetic poison/havoc
desired fact or scaling axiom is permitted. No such abstraction has been
implemented or formally tried in this packet.

## Controls and next admission

`checks/outslot/run_controls.py` is only run under the shared B scheduler and
8 GiB process-tree/time guard. It records each command and diagnostic outside the
checkout. The helper control uses independently expected accessor addresses,
CAS outcomes, modular wraparound and queue contents. The differential fixture
compiles the original and prospective TD separately, checks known parent/frontier
values and compares scalar/accelerated/empty-frontier outputs and operation counts.
It includes duplicate neighbors and visited vertices to exercise short-circuit
and failed-CAS behavior. Both binaries use ASan/UBSan.

Compiler negatives retain the uninitialized source read in both return and
out-store forms. A separate analyzer example detects an uninitialized pointee
after a pointer out-store; this demonstrates the ABI does not imply pointee
initialization, but is explicitly not a same-allocation-path allocator negative.
Changed/unknown/aliased source families are refused by exact source admission,
not by a claimed general alias analysis. These compiler/native checks are not
formal initializedness, span, RTE, alignment or C++ correspondence proofs.

hashes. Root alone may admit a fresh finite no-prover helper component, preserving
