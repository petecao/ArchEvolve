# Fresh count-to-model admission

2026-10-09 17:43 ET. Prospective local implementation and contract evidence only.

Fresh protected CPU pairing now replays the frozen mechanism model against its
exact persisted counts before runtime preflight. Immutable hashes previously
bound an estimate's saved bytes but did not prove that its numerical fields
followed from those inputs. A changed scalar total with synchronized sensitivity
base values could pass the generic payload checks. The new gate rejects it.

The producer and admission share the complete count-only semantic calculation. It
preserves exclusive-region maxima plus additive overheads, declared resource
domain overlap, exact source-call coverage, unknown propagation, trial contexts
and the median of whole-call trial estimates. Summing diagnostic region medians
is not a substitute for that whole-call median. Counts, target premises and model
inputs supply the calculation; no evaluation timing or future outcome enters it.

Admission binds the current frozen protocol, source/input and target identities,
bundle version, whole-call scope, thread/evidence classification and exact
numerical components. Orphan trial metadata, changed scoped inputs, fabricated
legacy-scope proofs and an altered target snapshot must refuse. An old estimator
bundle requires a new protocol for fresh execution. Archived validation continues
checking the saved pins and does not replay an old record under current formulas.
The complete parameter sensitivity report and its estimated-parameter list are
also recomputed, including halve/double whole-call scenarios, local components,
missing premises and impact ranks. Updating the saved base value or dropping
report rows cannot conceal an altered estimate.
