# Time Zone

Copied 2026-09-22 from the owner's MemAcc rules.

- All dates and times an agent writes are **Eastern Time (`America/New_York`)**:
  `YYYY-MM-DD HH:MM ET`. A bare `YYYY-MM-DD` is Eastern.
- Deadlines: quote the venue's zone first, then Eastern
  (`09-10 23:59 AoE = 09-11 07:59 EDT`).
- Machine-generated timestamps (run IDs, tool `...Z` strings, git dates)
  stay as produced; add the Eastern equivalent only when the reader must act on it.
